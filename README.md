# Komentář k zákonu č. 416/2023 Sb., o dorovnávacích daních

Odborný komentář k **zákonu č. 416/2023 Sb., o dorovnávacích daních pro velké nadnárodní skupiny a velké vnitrostátní skupiny (ZDD)** — české implementaci Pilíře 2 OECD a směrnice (EU) 2022/2523: globální minimální daň 15 %, přiřazovaná a česká dorovnávací daň, efektivní daňová sazba, bezpečné přístavy a správa Specializovaným finančním úřadem. Nový zákon — judikatura k němu dosud neexistuje.

Konsolidované znění: dokument e-Sbírky `SB-2023-00416_2025-09-03`.
